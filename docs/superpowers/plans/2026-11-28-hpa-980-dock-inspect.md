## Approach and risk

Implement the following three small checkpoints on this branch. Tests should cover behavior, not copy internal branching. Existing HPA-977 tests explicitly assert old Fit pixel retention; update those contracts, not the non-Fit regression coverage. The main risk is divergence between actual drawn transform, canvas pointer mapping and DOM Inspect after resize. Use the existing ResizeObserver and stage geometry rather than another layout system. Build placement uses the same internal "inspect" tool as Select, so do not gate by tool alone. Do not change rendering, Rust, persistence, or existing route timing units.
